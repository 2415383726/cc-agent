# 01: 交互作品经真实 Dify 展示并重开

发布状态：用户已确认，保留为历史草稿；实施请使用[正式票](../issues/01-interactive-answer-roundtrip.md)。

**What to build:** 用户在正常 Pi Agent 回答中得到一幅原生 SVG 交互作品，可以调参、展开和收起，并在刷新、清理浏览器缓存或重开会话后恢复原作品。首先打通不依赖共享图表库的最小完整链路，验证回答内嵌路线成立。

**Blocked by:** None (can start immediately)。

依据：[规格 v1](../spec.md) 的内容协议、完整回答、宿主与测试要求；共享样式和本地库由 02 扩充，内置生成技能由 03 提供。

## Acceptance criteria

- [ ] 先经真实 Dify 应用验证完整原生回答的输出与保存；至少两轮作品回答，其中一轮超过 16,000 字符。重取每轮历史的内容摘要一致；不依赖日志裁剪文本、最新 Pi 状态或浏览器缓存。固定作品可作为可控测试内容，明确区别于后续真实模型自由生成验收。
- [ ] 完整回答逐平台消息/运行合并，保留中间消息、工具活动和真实终态；已有裁剪文本不能挡住完整回答，多轮作品不并入最后一条消息，不重复显示。先完成这一必要整理，再接作品运行。
- [ ] 正常助手最终回答中的合法 `pi-visualize` 内容块能显示为作品；普通 HTML/JS 代码块、用户消息和工具结果中的同名内容不执行。协议主版本、套件主版本、根元素、标题、文字替代及内容身份遵守规格。
- [ ] 围栏必须真实闭合；原始片段不能包含作者文档壳、CSP 覆盖或外部资源。执行前按 UTF-8 检查 64 KiB 单块、两块/128 KiB 回答总额及字段上限；未知版本、不支持的依赖、无效和超限内容整块降级，不裁剪执行。超预算和多字节边界有针对性测试。
- [ ] 固定排队演示的滑块确实改变图形，暂停/重置可用；展开/收起保留同一实例及当次参数，刷新或重开恢复相同源码和初始参数。自定义片段样式仅影响自身作品。
- [ ] 基础宿主使用不授予同源能力的脚本沙箱，模型内容不进入主 DOM；凭据、父页面存储/DOM、模型请求、业务工具、表单、弹窗、下载和顶层导航能力不对作品开放。通过真实浏览器验证父页面访问失败及无公网请求，不能只检查 iframe 属性或源码字符串。
- [ ] 自动运行仅发生在完整回答收齐、内容合法并有可信完成状态时；流式半成品、停止、失败、预算耗尽或断流残片保持占位/兜底，不自动运行或重发。基本就绪/尺寸/错误通道绑定实际 frame 与当前会话，尺寸限幅，未知终态不伪造成完成。
- [ ] live、history、replay 共用消息分段、校验与宿主；当前票至少验证带正常过程日志的两轮历史恢复。浏览器运行错误能给出文字兜底；切换会话释放旧作品且不过期回写。
- [ ] 必要的投影、解析和组件行为测试通过，并留下真实 Dify、浏览器和内容摘要证据。若原生回答保存或隔离路线失败，记录可复现限制并返回技术取舍，不以假数据、仅回放截图或新增服务代替验收。

## Scope notes

当前票只交付原生 HTML/CSS/JS、SVG/canvas 的最小链路；不提前制作 D3/Lucide 套件或完整技能。隔离与内容边界是本票完成条件，不推迟到 04。完整历史分页、无过程日志手动查看和异常组合由 04 扩展。
