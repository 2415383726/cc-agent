## Acceptance criteria

- [ ] 内部 Tasks 工具覆盖现有创建、更新、查询和列表行为，模型通过 Pi 调用工具后能使用结果回答。
- [ ] 任务完整状态随 agent_state 保存；重建运行后任务内容、状态与允许 metadata 保持一致，送模采用受控投影。
- [ ] 保留任务更新校验及稳定标识；非法任务请求形成配对工具错误，不破坏其他会话状态。
- [ ] 简单查询无需创建 Task；Task 的完成仅表示助手进度，不等同于业务作业或写操作已经成功。
- [ ] 可保留短 job/operation/evidence 引用，但完整业务数据与产物仍由外部工具读取，不创建额外存储。
- [ ] 两个入口能消费任务相关结果/活动；容量处理不静默丢掉仍需继续的任务。

## Implementation context

- 按已确认规格实施：社区 Python Pi core/harness 0.6.0 为初始基线，单项目单插件双入口；Dify 持有模型/工具授权与唯一跨轮状态。内部只提供认知工具，不恢复已移除能力。
- 内部工具只处理认知与会话；不恢复 Memory、工作区、MinIO 或脚本执行能力。
- 六项用户命令在 14 统一完成，本票不以 /status 命令替代 Tasks 工具链路验证。
