ZCode's own visualize resources use Apache-2.0. Its vendor resources retain
their separate licenses: D3 uses ISC; Lucide uses ISC with the MIT-derived
Feather icon notice. These complete notices are stored beside the scripts.
Floating UI is not shipped; tooltip positioning is project-authored.

The published visualize/manifest.json records exact versions, paths, source
provenance, byte lengths and script/license checksums. No resource is fetched
from the source repository at runtime.
