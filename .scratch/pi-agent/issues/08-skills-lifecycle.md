# 08: 应用技能激活、资源读取与过程展示

**What to build:** 用户或模型选用当前有效应用技能，按需读取受限资料，工作台展示真实使用轨迹，下一轮按资格继续恢复。

**Blocked by:** [07 状态容量、历史与会话恢复](07-state-history-recovery.md)

**Status:** ready-for-agent

**Version:** v2；用户已确认拆分并发布。按必要前置完成情况选择实施前沿；当前尚未实施。

**Parent:** [Agent 工作台规格 v2](../spec.md)

**Spec coverage:** US10、US11、US17、US18、US19、US20、US21、US29；V08、V09、V13、V18。这是本票涉及的行为，不表示本票单独签收整个验收场景；最终平台证据由 17、18 补齐。

## Acceptance criteria

- [ ] 接入内置及应用配置技能发现、资格检查、列表和显式用户/模型激活；不强制普通问答激活技能或创建 Tasks。
- [ ] 使用 Pi 资源/hook/消息机制注入有效正文，不维护平行技能循环；注入发生在合法工具配对之后。
- [ ] 资源读取仅限所属技能受控文本，支持分页/结果限制；绝对/相对越界、错误资源和失效技能拒绝。
- [ ] 活动技能进入权威状态并在下轮重新检查可见性；配置更新/资格撤销后不继续注入旧正文。
- [ ] Vue 技能卡/活动来自真实激活与读取事实，适配实际 YAML/资源标识，不靠伪造 SKILL.md 路径或百分比；历史刷新可读。
- [ ] 必要上下文/用量投影反映技能实际加入的内容；不把配置凭证或技能外资源加入提示/日志。
- [ ] 从策略入口和工作台覆盖用户激活、模型激活、分页、越界、资格变化和重建恢复，原有有效工具结果不被技能注入破坏。

## Implementation context

- 旧技能提示与资源读取可按边界迁入；v2 不要求复刻 answers-ui/旧结构化答案技能。
- 只负责业务指导与受限文本资料，不添加工作区、通用本地 read、远程技能管理或任意脚本。
- 当前只有少量骨架和依赖导入，前置票是否完成须检查实际验收记录。v2 是唯一范围依据，不恢复旧 AG-UI 双入口、Tasks、六命令或旧前端兼容要求。
- 每票包含自身完整行为及必要验证，优先从策略入口、真实 SDK 消息和浏览器观察；只给易变接入点补有限契约测试，不为每个内部 helper 建测试。
