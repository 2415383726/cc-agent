# 06: 审批卡

**What to build:** 与问卷同卡片体系的工具授权审批卡：工具名与参数可见、范围选择（once/session）、批准与拒绝两个动作、拒绝后呈现「已拒绝且未执行」非执行态。审批是独立于问卷的待交互类型：阻断运行、优先可操作；从保存态恢复的待审批进入即呈现并可操作，恢复不等于授权。

**Blocked by:** 05.

**Status:** ready-for-agent

- [ ] approval 回放可走完整授权流：批准与拒绝两条路均可闭环
- [ ] 拒绝后卡片呈现已拒绝且未执行状态
- [ ] scope 选择（once/session）随决定一并提交
- [ ] 保存态恢复的待审批卡可直接操作（savedState 测试护栏保持全绿）
- [ ] 组件测试覆盖 scope 选择、两个决策路径、恢复态渲染
