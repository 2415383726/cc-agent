# 由策略参数配置远程 MCP 工具

生产环境使用 Dify 1.15.0，工具调用需要携带当前业务用户的 header，而该版本的原生 MCP 配置不能按请求替换 header。决定为两个 CC Agent 策略增加 `mcp_servers_config`，由 Dify 的 Agent 参数模板先替换用户变量，再由插件连接远程 MCP 服务，复用统一工具目录、调度和输出。

这是对 ADR-0001 中外部工具注入边界的扩展：外部能力也可来自应用配置的远程 MCP 服务；会话状态仍由 Dify 承载，内部工具仍只处理认知与会话。连接和凭证限于当前运行，不共享用户身份，不支持本地 stdio 或启动服务端进程。接受维护 MCP 客户端依赖的成本，以避免为用户身份透传修改生产 Dify 或更换现有界面协议。
