# 采用社区 Python Pi Harness 作为执行内核

用户确认采用 `pi-agent-core-lc` + `pi-agent-harness-lc` 构建 Pi Agent；已核对的 `0.6.0` 作为初始依赖基线，后续固定完整依赖并验收。用户的主要目标是以开源社区的设计、实现和测试基础改善自研 Harness，在受限 Dify 环境中稳定运行当前全部功能，而不是持续跟随官方 Pi 版本。

Python 接入省去 JavaScript 运行环境交付和跨语言通信，更适合完全离线、单 `.difypkg`、生产 arm64/测试 amd64 的约束；代价是承认社区实现的行为差异，并在 Dify 适配中补齐预算、溢出恢复、持久确认和同步/异步协调。选型确认不代表这些能力已经实现或验证；官方 Pi 继续作为设计与行为参考，Dify 仍持有跨轮状态及当前调用的模型/工具授权。

用户后续在 [ADR-0007](0007-agent-workbench-scope.md) 放宽全量旧功能及固定前端兼容要求；本条内核选型与 Dify 资源归属继续有效。
