## Acceptance criteria

- [ ] 两个入口支持当前有效的 /help、/status、/context、/cost、/compact 和 /reset，参数及返回语义沿用当前行为基线。
- [ ] /status、/context、/cost 基于真实会话投影、任务/技能及预算统计，不引用另一份历史或伪造模型成本。
- [ ] /compact 使用 10 的社区压缩与统一预算，输出压缩活动、有效快照和可信终态；压缩失败不伪称完成。
- [ ] /reset 清理当前新插件的历史、Tasks、会话授权、活动技能及待处理中断；重建后确认原问题不再执行。
- [ ] 重置不操作外部业务记录、产物、旧插件会话或远程服务；不重新加入已移除演示和 Memory 命令。
- [ ] 命令结果在 AG-UI/原生输出及前端均可用；状态提交顺序和失败语义与普通运行一致。
- [ ] 记录调用统计说明哪些命令无需模型、哪些压缩调用计入成本，避免命令路径绕过预算或凭证过滤。
