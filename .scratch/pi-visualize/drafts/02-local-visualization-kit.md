# 02: 使用内置样式与本地资源完成交互讲解

发布状态：用户已确认，保留为历史草稿；实施请使用[正式票](../issues/02-local-visualization-kit.md)。

**What to build:** 用户从真实 Dify 回答打开一幅带统一样式、基础控件、D3 图表和 Lucide 图标的交互作品；浅深主题、窄屏和键盘操作均可用，部署后不需要公共 CDN。此票交付可演示的运行套件能力，不仅是样式或依赖文件。

**Blocked by:** 01 — 交互作品经真实 Dify 展示并重开。

依据：[规格 v1](../spec.md) 的内置样式、控件、本地资源、版本与许可要求。

## Acceptance criteria

- [ ] 在 01 的正常回答链路中展示使用共享套件的完整作品；作者只提供片段并声明支持的本地库标识，宿主在作者脚本前提供依赖，不复制整套 CSS 或第三方库进回答。
- [ ] 提供规格列出的公共主题、六个稳定图表系列色及布局、按钮、表单、表格、文字与辅助技术样式。样式和行为有一个公共契约；普通聊天、其他作品及作者片段互不污染。
- [ ] 交互示例同时证明 slider/select/toggle/button、tabs、tooltip 和图标初始化可用，状态改变有实际图形反馈；共享控件的焦点、标签、触摸目标与禁用态可用，tooltip 不成为必要信息的唯一来源。
- [ ] 固定本地 D3 7.9.0、Lucide 1.17.0；若采用 Floating UI，则固定规格基线版本。通过受支持库标识加载，无任意 URL、动态包加载或 CDN 回退；未知标识和缺失资产得到可读兜底。
- [ ] 真实浏览器中演示 D3 图表与原生图形的主题切换，canvas 若使用也能重绘；320px 和桌面宽度下控件、标签和单位不遮挡，键盘能完成主要交互，减少动画偏好得到尊重。
- [ ] 使用工作台本地发布资产和系统字体，实际网络观测中作品无公网请求；新增库、tooltip 和图标能力仍遵守 01 的父页面/凭据隔离、完成门控与本地交互边界，不新增 Agent 桥。
- [ ] 带套件的作品经真实 Dify 保存并刷新恢复，原作品摘要一致、参数回到初始值；展开/收起不因共享控件或资源加载而重建 frame。
- [ ] 套件、资源标识、实际版本、来源、校验和与许可证有发布清单；复用 ZCode 资源时保留固定来源、必要 NOTICE 和修改说明。第一版版本支持明确，不支持的套件版本可读降级。
- [ ] 留下可供 03 编写技能资料的准确能力目录和示例，模型可读 API 文档与第三方运行资产分离。工作台相关测试、构建、静态检查及真实浏览器交互检查通过，不用逐 CSS 类镜像测试代替行为验收。

## Scope notes

不引入日历、Tweak、变体轮播或在线地图，不移植 ZCode React/Electron 宿主。本票完成后即有可独立演示的本地运行套件；模型主动生成由 03 接通。
