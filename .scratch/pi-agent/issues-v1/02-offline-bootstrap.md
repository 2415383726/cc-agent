## Acceptance criteria

- [ ] 锁定 Python 3.12 兼容的完整运行依赖树、目标 wheels、版本清单与校验和，包含 Pi 实际依赖的 LangChain 等包；开发工具不进入运行包。
- [ ] 分别构建 amd64/arm64 的单插件 .difypkg；包不依赖旧插件目录或参考源码，且不会混入错误架构的二进制依赖。
- [ ] 两架构均进行目标平台离线依赖解析及 wheel 标签/完整性校验，不允许缺包后回退公网或源码在线构建。
- [ ] 在干净、禁止公网下载的 amd64 运行环境安装并启动基础插件，通过受控模型服务完成双入口基本问答与状态恢复。
- [ ] 证明安装、启动及普通执行不会自动下载代码、技能资源或依赖，也不要求额外 Node、旁路服务或新增公共模型/遥测服务。
- [ ] 提供可重复构建与验证说明；之后新增运行依赖或资源必须同步更新锁定和离线包，不能等到发布时再手工补齐。
- [ ] arm64 的静态解析结果与实际运行结果分别记录；本票不以交叉解析替代 17 的真实 arm64 安装运行。
