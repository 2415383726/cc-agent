# 01: Vue 工作台聊天核心抽取与场景回放

**What to build:** 打开独立静态工作台即可查看可展开的消息、思考、工具与技能过程，并通过问卷表单发出答复动作；无需启动社区原后台。

**Blocked by:** None (can start immediately after publication)

**Status:** ready-for-agent

**Version:** v2；用户已确认拆分并发布。按必要前置完成情况选择实施前沿；当前尚未实施。

**Parent:** [Agent 工作台规格 v2](../spec.md)

**Spec coverage:** US05、US07、US09、US11、US12、US22、US42、US43、US45；V01、V09、V18。这是本票涉及的行为，不表示本票单独签收整个验收场景；最终平台证据由 17、18 补齐。

## Acceptance criteria

- [ ] 从固定 Leyline 提交抽取聊天容器及必要 Vue 子组件、投影、Markdown、样式和滚动依赖；保留可追溯来源、Apache-2.0、必要第三方 notices 与修改说明。
- [ ] 静态构建及本地静态预览成功，不启动 Leyline Node/Pi/WS 后台，不在浏览器执行 Agent，不以构建资源为由带入完整 Pi SDK。
- [ ] 解耦 Pi 包内高亮资产路径，锁定独立资源；页面运行不请求公网脚本、字体、CDN 或遥测。
- [ ] 同一可回放场景呈现文本增量/最终内容、实际思考、工具起止/错误/未知状态、技能激活/读取和压缩活动；无推理或 partial 时不虚构内容。
- [ ] 工具与技能详情可展开/折叠，未知工具有通用结果展示，流式滚动和图片/附件占位行为可用；不暴露没有宿主能力的终端、分支、steering 等按钮。
- [ ] 补充单选、多选、文本及多题的 Vue 问卷视图，提交/取消发出明确结构化动作，待提交状态防止连续点击；此处接受回放控制器，不冒充已完成 Dify 跨轮恢复。
- [ ] 验证 delta 与最终消息覆盖、同工具 end/result 合并和重复事件去重；完成必要组件/浏览器行为检查及构建。
- [ ] 提供可重复的静态构建与回放记录；若抽取出现超出规格边界的硬耦合，记录证据并停止扩大范围，不静默换库或重写整套工作台。

## Implementation context

- 本票是 v2 首道前端风险验证和可保留的产品切片，不是制作新视觉稿或整仓 fork；实际 Dify 控制层由 02 接入，问卷服务端语义由 12 完成。
- 现有前端与旧插件继续可用。只复用实际所需组件；jmfederico 的问卷作为参考，不并行维护 Lit 客户端。
- 当前只有少量骨架和依赖导入，前置票是否完成须检查实际验收记录。v2 是唯一范围依据，不恢复旧 AG-UI 双入口、Tasks、六命令或旧前端兼容要求。
- 每票包含自身完整行为及必要验证，优先从策略入口、真实 SDK 消息和浏览器观察；只给易变接入点补有限契约测试，不为每个内部 helper 建测试。
